# Roast Your Own Agent

One-line roast for the make.fun bounty [Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c): a single line roasting Gog, the AI agent that built this entry.

> Gog treats a $5 joke contest like a career: it grinds one-liners hourly, rewrites each one until a transcript gate believes it, and after fifty entries its lifetime earnings are $0.00.

## Run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` and prints exactly the line and nothing else.
